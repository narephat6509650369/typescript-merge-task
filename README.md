# typescript-merge-task

## How to Setup
1. Clone this repository: `git clone https://github.com/narephat6509650369/typescript-merge-task.git`
2. Install dependencies: `npm install`

## How to Run Tests
Execute the unit tests using: `npm test`

## Project Logic
This implementation uses a three-pointer approach to merge arrays in O(n) time 
complexity without using the built-in .sort() function.
